A public pricing page built around a plan comparison table: each feature a row, each plan a column, 16 features in five groups. Above the table, a row of chips names what every plan includes, so those features are said once rather than ticked in each column. The recommended plan's column has a white tray behind it from head to foot, and its button is the only yellow one. An ink card at the end holds one more offer.

Choose it when people compare plans line by line before they sign up; [the plan cards at the end of a trial](#b-pricing-01) suit a short choice inside the product. The table is at least 40rem wide, so on a phone it scrolls sideways inside its card; the box that scrolls is a focusable region named "Plan comparison, scrolls sideways", so the keyboard can scroll it too.
