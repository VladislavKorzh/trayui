Notification settings laid out by channel: a card each for email and the phone app, one for text messages, and one for quiet hours at night. A switch in a channel's corner turns off the rows under it, a row that must stay on is locked, and the text messages card is an empty state that asks for a phone number first. There is no save button: every switch and select saves the moment it moves and says so in a toast. Pick it when people think in channels; for a grid of events against channels, use [notification preferences](#c-notification-preferences).

The same event can sit under two channels, so each switch carries hidden words, ", by email" or ", in the phone app", and is announced with its channel. The toasts arrive in a polite live region. Below 56rem the four cards stack in one column.
