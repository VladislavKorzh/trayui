A flyout menu for each section: an item opens its second level in a dropdown beside the sidebar, so the column keeps one row per section however many pages sit under it. Each such item is a button that announces its menu and keeps `aria-expanded` in step. Enter or the down arrow opens the menu with focus on its first page, the arrow keys move through it, and Escape closes it and puts focus back on the item. The section that holds the current page stays solid ink with `aria-current="true"`, and the page inside its menu is marked as the current page.

Pick it when people go straight to one page and do not need the tree in view; for browsing, [items that fold](#b-sidebar-04) show the pages in place. `tray-sidebar--flyout` lets the menus out past the tray's edge, so the tray cannot scroll: keep it shorter than the smallest window. In the phone sheet there is no room beside the sidebar, so each menu opens under its item.
