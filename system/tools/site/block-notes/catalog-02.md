A product listing with a filter column, for a range that needs more than a few menus. The column holds checkboxes for the type and the size, a price limit on a slider and an "In stock only" switch. Within a group any ticked box may match, across groups all must, and the price is a ceiling. Above the results sit the count, the sort and a switch between rows and a grid of cards, and when nothing matches, an empty state offers to clear the filters. For a range that three menus cover, the [catalog with filters on top](#b-catalog-01) gives the products the full width.

The count is a polite live region, so each change is read: "9 products". The slider says "Up to $120" through `aria-valuetext` rather than a bare number. Below 56rem the column leaves the page, and the Filters button, whose badge counts the groups in use, opens the same column as a sheet from the end edge.
