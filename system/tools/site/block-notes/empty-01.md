An empty state for a new account: the orders screen of a workspace on its first day, before the first order. Instead of a bare table it offers a setup checklist of five tasks with a progress bar, a card to import orders kept in a spreadsheet, and the orders table itself, its headers in place and one row holding the message and a button to place a test order. The sidebar foot shows the trial's meter of orders at 0 of 50.

This is the first-use kind of [Empty](#c-empty) state; take [No results](#b-empty-02) when a search or a filter finds nothing, and [No access](#b-empty-03) when the data exists but the person may not see it. Below 56rem the checklist and the import card stack. The checklist marks the next task with `aria-current="step"`, and finishing a task moves focus to the button of the one after it.
