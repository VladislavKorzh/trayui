The cart as the first step of a checkout, on a plain screen with the wordmark and a link back to the shop. Each line has a quantity stepper that goes down to zero; at zero the line stays and says how to put it back, so a slip costs nothing. A meter counts towards free delivery, the gift box switch shows a note field with a 140-character count, and a wrong promo code marks the field invalid and says why. Choose it to open a checkout in steps that goes on to the [one-page checkout](#b-checkout-02); a [cart page inside the shop](#b-shop-02) keeps the header and the footer instead.

The total is a polite live region, so each change to it is read. Below 34rem the stepper shows the name of the current step only, and the other names stay for a screen reader. Below 64rem the summary moves under the cart.
